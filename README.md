# Sorting Visualizer

Welcome to Sorting Visualizer! I built this application because I was fascinated by sorting algorithms, and I wanted to visualize them in action. I hope that you enjoy playing around with this visualization tool just as much as I enjoyed building it. 


Overview
A web-based interactive visualization tool built with React.js that animates popular sorting algorithms in
real time. 
DSA Concepts Used
• Merge Sort: Divide-and-conquer with O(n log n)
time — visualized with color changes
• Quick Sort: Pivot-based partitioning with
animated swaps
• Heap Sort: Priority queue / max-heap structure
building shown visually
• Bubble Sort & Insertion Sort: Classic O(n2)
comparisons animated bar by bar
• Array manipulation and animation queue
management using JavaScript closures
Key Features
• Live animation of 5+ sorting algorithms with
adjustable speed
• Color coding: turquoise = default, red = being
compared
• Randomize array button to generate new test
cases
• Responsive design optimized for Google
